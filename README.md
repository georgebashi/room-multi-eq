# Room Multi EQ

An audio plugin for applying independent parametric EQ to left and right channels, designed for loading [Room EQ Wizard](https://www.roomeqwizard.com/) (REW) filter profiles. Available as AudioUnit (macOS), VST3 (Windows), and LV2 (Linux).

## Overview

Room Multi EQ lets you apply room correction filters generated by [Room EQ Wizard](https://www.roomeqwizard.com/) to stereo audio. Unlike typical EQ plugins, it provides completely independent EQ processing for left and right channels—essential for proper room correction where each speaker interacts differently with your room.

**Key Features:**
- 16 parametric EQ bands per channel (32 total)
- Import filter settings directly from REW export files
- Peak, Low Shelf, and High Shelf filter types
- Per-band bypass and global master bypass
- Zero latency (IIR filters)
- Cross-platform (macOS, Windows, Linux)

## Installation

### Pre-built Plugin

Download the latest release from the [Releases](https://github.com/georgebashi/room-multi-eq/releases) page and copy to your plugin folder:

**macOS:**
- AU: `~/Library/Audio/Plug-Ins/Components/`
- VST3: `~/Library/Audio/Plug-Ins/VST3/`

**Windows:**
- VST3: `C:\Program Files\Common Files\VST3\`

**Linux:**
- LV2: `~/.lv2/`

### Build from Source

Requires CMake 3.22+ and a C++17 compiler.

```bash
# Clone the repository
git clone https://github.com/your-username/room-multi-eq.git
cd room-multi-eq

# Configure and build
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

On macOS, verify the AudioUnit installation:
```bash
auval -v aufx Rmeq Gbsh
```

## Usage

### Importing REW Filters

1. In Room EQ Wizard, generate your correction filters
2. Export filters: `File > Export > Filter Settings as Text`
3. Open Room Multi EQ in your audio host
4. Click "Import" for the left or right channel
5. Select your exported .txt file

### REW Export Format

Room Multi EQ parses the standard REW filter export format:

```
Filter  1: ON  PK       Fc    63.0 Hz  Gain  -5.2 dB  Q  4.32
Filter  2: ON  PK       Fc   125.0 Hz  Gain  -3.1 dB  Q  2.87
Filter  3: ON  LS       Fc    80.0 Hz  Gain  +2.0 dB  Q  0.71
Filter  4: ON  HS       Fc  8000.0 Hz  Gain  -1.5 dB  Q  0.71
Filter  5: OFF PK       Fc   250.0 Hz  Gain  -2.0 dB  Q  3.50
```

**Supported filter types:**
- `PK` - Peak (parametric bell)
- `LS` - Low Shelf
- `HS` - High Shelf

### Typical Workflow

1. Measure your room with REW (left and right speakers separately)
2. Generate EQ filters in REW for each channel
3. Export each channel's filters to separate .txt files
4. Load the left filters into the left channel, right into right
5. Enable the plugin in your DAW or system audio chain
